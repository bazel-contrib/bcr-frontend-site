OpenGrm Libraries

OpenGrm is a collection of open-source libraries for constructing, combining, applying and searching formal grammars and related representations, using the OpenFst library for their underlying finite-state models. This collection includes:

  • Baum-Welch: parameter estimation and decoding using a channel model represented as weighted finite-state transducers (WFSTs).
  • NGram: making and modifying n-gram language models encoded as WFSTs.
  • Pynini: a Python library for compiling a grammar of strings, regular expressions, and context-dependent rewrite rules into WFSTs.
  • SFst: normalizing, sampling, combining, and approximating stochastic finite-state transducers.
  • Thrax: a set of tools for compiling grammars expressed as regular expressions and context-dependent rewrite rules into WFSTs.
  • Several helper libraries for formal grammar compilation functions, path iteration, rewrite rule operations, and string automata manipulation.
  • Bazel scaffolding for grammar testing.

Please also see https://www.opengrm.org for extensive documentation.

Building

Prerequisites

  • A C++17 compatible compiler such as gcc >= 7.5.0 or clang >= 14.0.0.

Bazel

OpenGrm can be built and tested using Bazel 9.1.1 or newer.

# Build the entire project
bazel build //...

# Run all tests
bazel test //...

Alternatively, Bazelisk can be used for building.

Example: Baum-Welch trainer

The following example builds Baum-Welch trainer using Bazelisk on macOS:

# Get OpenGrm and download Bazelisk.
BAZELISK_VERSION=...
git clone https://github.com/google-research/opengrm.git
wget https://github.com/bazelbuild/bazelisk/releases/download/v${BAZELISK_VERSION}/bazelisk-darwin-arm64
chmod +x bazelisk-darwin-arm64

# Build all the Baum-Welch tools and libraries, and run the tests.
cd opengrm
../bazelisk-darwin-arm64 build -c opt opengrm/baumwelch/...
../bazelisk-darwin-arm64 test -c opt opengrm/baumwelch/...

# Use the tool.
bazel-bin/opengrm/baumwelch/baumwelchtrain --help

CMake

OpenGrm can also be built with CMake 3.22 or higher.

Prerequisites

  • If you are building Thrax grammar compiler, the required prerequisite is GNU Bison parser generator (version 3.8 or higher), which on Linux can be installed using the system package manager, e.g., sudo apt-get install bison.
  • For building Python components (e.g., Pynini):
    • Python 3.6 or higher and development headers (e.g., python3-dev).
    • Cython (pip install cython).
    • absl-py (pip install absl-py) to run tests.

Build and Install

Dependencies like Abseil, GoogleTest, Google Protocol Buffers and OpenFst are automatically downloaded using FetchContent (or find_package).

# Configure the project.
# Use -DOPENGRM_BUILD_TESTS=OFF to skip building tests.
cmake -S . -B build \
  -DOPENGRM_ENABLE_BAUMWELCH=ON -DOPENGRM_ENABLE_SFST=ON \
  -DOPENGRM_ENABLE_NGRAM=ON -DOPENGRM_ENABLE_THRAX=ON

# Build the project
# On Linux, `-j$(nproc)` can be used to reduce typing.
# https://man7.org/linux/man-pages/man1/nproc.1.html
cmake --build build -j$(getconf _NPROCESSORS_ONLN)

# Run tests
ctest --test-dir build --output-on-failure -j$(getconf _NPROCESSORS_ONLN)

# Install the project
# Use --prefix to specify an installation directory
cmake --install build --prefix /usr/local

Prefer shared libraries when building Python extensions.

# Configure Pynini.
cmake -S . -B build -DOPENGRM_ENABLE_PYNINI=ON -DBUILD_SHARED_LIBS=ON

# Build.
cmake --build build -j$(getconf _NPROCESSORS_ONLN)

# Run tests.
ctest --test-dir build --output-on-failure -j$(getconf _NPROCESSORS_ONLN)

Configuration Options

You can enable or disable specific features using CMake options (default is OFF unless noted):

Option Description Default
OPENGRM_ENABLE_BAUMWELCH Build Baum-Welch trainer and decoder components OFF
OPENGRM_ENABLE_NGRAM Build N-gram library and tools OFF
OPENGRM_ENABLE_SFST Build stochastic finite-state transducers OFF
OPENGRM_ENABLE_PYNINI Build Pynini grammars (Python) OFF
OPENGRM_ENABLE_THRAX Build Thrax grammar compiler OFF

Additional options include:

Option Description Default
BUILD_BUILD_SHARED_LIBS Build shared rather than static libraries OFF
OPENGRM_BUILD_TESTS Build unit tests ON
OPENGRM_ENABLE_BIN Build command-line executables ON
OPENGRM_RUN_SLOW_TESTS Run very slow tests as part of ctest OFF

Example usage:

cmake -S . -B build -DOPENGRM_ENABLE_SFST=ON -DBUILD_SHARED_LIBS=ON

Release History

The main branch includes the full historic release lineage of OpenGrm's constituent libraries (ngram, thrax, pynini, sfst, baumwelch) prior to their consolidation into a single repository.

Listing Tags and Releases

To list all historic component release tags:

git tag -l

Release tags follow the format <component>-<version> (e.g., thrax-1.3.8, pynini-2.1.5, ngram-1.3.14).

Checking Out or Viewing a Specific Release

To check out a specific historic release:

git checkout <tag-name>

To view the change history of a specific component:

git log --full-history -- <component>/

For example, to trace the commit history of Thrax or Pynini:

git log --full-history -- thrax/
git log --full-history -- pynini/
